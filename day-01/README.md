# Day 01 - Python Calculator 🧮

## About the Project
A simple calculator built using Python.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division by zero error handling.
- Invalid operation handling.

## Technologies
- Python

## How to Run
Open the terminal inside the `day-01` folder and run:

```bash
python calculator.py
```

## Example

```text
Enter the first number: 10
Enter the operation: +
Enter the second number: 5
15.0
```

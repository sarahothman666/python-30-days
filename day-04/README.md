# Day 04 - Contact Book 📒

## Project Description
A simple Contact Book application built with Python. It allows users to manage their contacts through a menu-driven interface.

## Features
- Add new contacts with names and phone numbers.
- Prevent duplicate contact names.
- View all saved contacts.
- Search for contacts by name.
- Delete contacts.
- Exit the application.

## Technologies Used
- Python
- Dictionaries
- Functions
- While Loop
- For Loop
- If / Elif / Else
- Dictionary Methods (`items()`)
- User Input and Output

## How to Run

1. Make sure Python is installed.
2. Open the project folder.
3. Run the following command:

```bash
python contact_book.py
```

## Example

```text

4- Delete Contact
5- Exit
```

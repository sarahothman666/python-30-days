# Day 03 - Text Analyzer 📝

## Project Description
A Python program that analyzes text and provides useful statistics.

## Features
- Count characters.
- Count words.
- Count vowels.
- Count consonants.
- Find the longest word.
- Convert text to uppercase and lowercase.

## Concepts Learned
- Python Functions
- Parameters and Arguments
- Return Statement
- String Methods
- Loops
- Built-in Functions (`len`, `max`)

## How to Run
```bash
python text_analyzer.py
```

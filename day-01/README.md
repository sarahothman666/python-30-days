# Day 01 - Python Calculator 🧮

## About the Project

A command-line calculator built with Python that performs basic arithmetic operations and handles common input errors.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division by zero error handling.
- Invalid operation handling.

## Technologies

- Python 3

## Requirements

- Python 3.x

## Project Structure

```text
day-01/
└── calculator.py
```

## How to Run

1. Open the terminal inside the `day-01` folder.
2. Run the following command:

```bash
python calculator.py
```

## Example

```text
Enter the first number: 10
Enter the operation: +
Enter the second number: 5

15.0
```

## What I Learned

- Working with Python variables.
- Using conditional statements (`if`, `elif`, `else`).
- Handling user input.
- Performing basic arithmetic operations.
- Handling common errors.
